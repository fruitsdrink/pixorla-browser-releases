# Pixorla Browser

Pixorla 的桌面预览客户端：把作品的实时预览放进独立桌面窗口——多视口、多标签，与网页编辑器实时同步。它不是桌面 IDE，代码仍在网页编辑器里写，桌面窗口只负责「看」。

The desktop preview client for [Pixorla](https://pixorla.design): a standalone window with multi-viewport, multi-tab live preview of your fiddles, synced with the web editor in real time. It is not a desktop IDE — editing stays in the browser, the window is for viewing.

> 本仓库仅用于分发安装包，不含源代码。This repository distributes installers only — no source code lives here.

## Download / 下载

从 [Releases](https://github.com/fruitsdrink/pixorla-browser-releases/releases) 页获取对应平台的安装包：

| Platform | File |
| --- | --- |
| macOS（Apple Silicon / M-series） | `Pixorla-Browser-<version>-mac-arm64.dmg` |
| Windows 10 / 11（64-bit） | `Pixorla-Browser-<version>-win-x64.exe` |
| Linux（x86_64） | `Pixorla-Browser-<version>-linux-x86_64.AppImage` · `Pixorla-Browser-<version>-linux-amd64.deb` |

安装包暂未签名（unsigned）：

- macOS：首次打开请在 Finder 中右键点击应用选「打开」，或在「系统设置 → 隐私与安全性」中点「仍要打开」。On first launch, right-click the app in Finder and choose Open, or approve it in System Settings → Privacy & Security.
- Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。If SmartScreen appears, click More info → Run anyway.
